## 1. 系统简介

TCL表格比对系统用于每日跟踪物料缺料变化情况。系统自动比对昨/今日的缺料Excel表格，计算变化量，支持出货匹配、物料分类导出、批量导入等功能，帮助供应链团队高效管理物料缺料问题。

**核心能力：**
- 自动比对昨/今日缺料表格，生成差异报告
- 出货匹配与批量删除
- 按物料类别自动分类导出
- 多文件批量导入与模糊搜索
- 本地/局域网服务器双模式数据存储

## 3. 网络模式设置

侧边栏顶部的"网络模式"区域用于切换数据存储方式。

### 3.1 本地模式（默认）

点击侧边栏中的 **「本地」** 按钮。

- 数据保存在本地JSON缓存文件中
- 无需网络连接
- 适合单机使用

状态指示器显示：`● 本地模式`（绿色）

### 3.2 服务器模式

点击侧边栏中的 **「服务器」** 按钮。

- 数据通过局域网服务器统一存储
- 适合多人协作场景
- 需要先启动服务器

**操作步骤：**
1. 在服务器地址输入框中输入服务器地址（如 `http://192.168.1.100:5000`）
2. 点击 **「测试」** 按钮验证连接
3. 连接成功后，点击 **「服务器」** 按钮切换模式

状态指示器显示：
- `● 服务器模式`（蓝色）— 已连接
- `● 连接失败`（红色）— 无法连接服务器

**启动服务器（管理员操作）：**
```bash
python server.py --host 0.0.0.0 --port 5000
```

> **提示：** 网络连接失败时，系统会自动降级为本地模式，不会丢失数据。

## 4. 表格比对（核心功能）

这是系统最核心的功能，用于比对昨/今日的物料缺料表格，自动计算变化量并导出差异报告。

### 4.1 准备文件

在开始比对前，请准备好以下文件：

| 文件 | 是否必须 | 说明 |
|------|---------|------|
| 昨天表格 | **必须** | 昨日从SAP/ERP导出的缺料Excel文件 |
| 今天表格 | **必须** | 今日从SAP/ERP导出的缺料Excel文件 |
| 出货表格 | 可选 | 供应商本次送货的Excel文件 |

> **Excel格式要求：** 文件第一行必须为表头，且包含 `物料号`（或 `物料编码`）列。建议同时包含 `销售订单`、`销售订单行号`、`内需单号` 列以确保精确匹配。

### 4.2 操作步骤

**第一步：选择文件**

1. 点击侧边栏的 **「表格比对」**
2. 点击 **「昨天表格」** 右侧的 **「浏览」** 按钮，选择昨日缺料Excel文件
3. 点击 **「今天表格」** 右侧的 **「浏览」** 按钮，选择今日缺料Excel文件
4. （可选）点击 **「出货表格」** 右侧的 **「浏览」** 按钮，选择本次送货Excel文件
5. 确认 **「输出目录」** 是你希望保存结果文件的位置（默认为程序所在目录）

**第二步：执行比对**

点击 **「开始比对并导出差异表格」** 按钮。

系统将自动执行以下操作：
1. 读取昨/今日Excel数据
2. 按复合键 `物料号|销售订单|销售订单行号|内需单号` 逐条匹配
3. 计算每条记录的 `变化量 = 今天总缺料 - 昨天总缺料`
4. 如果导入了出货表格，自动关联 `本次送货数量`
5. 按优先级排序（异常项在前，变化量大的在前）
6. 导出带颜色标记的差异Excel
7. 将比对结果写入本地数据库

**第三步：查看结果**

比对完成后：
- 界面下方的"比对结果"区域会显示详细日志
- 差异Excel文件已自动保存到输出目录，文件名格式：`缺料差异_YYYYMMDD_HHMMSS.xlsx`

### 4.3 导出文件说明

导出的差异Excel包含以下关键列：

| 列名 | 说明 |
|------|------|
| 序号 | 自动编号 |
| 物料号 | 物料编码 |
| 昨天总缺料 | 昨日该物料的缺料数量 |
| 今天总缺料 | 今日该物料的缺料数量 |
| 变化量 | 今天 - 昨天（正数表示缺料增加，负数表示减少） |
| 剩余出货量 | 今天总缺料 - 本次送货数量 |
| 本次送货数量 | 从出货表格中匹配到的送货数量 |
| 物料描述 | 物料名称描述 |
| 供方 | 供应商名称 |

**颜色标记说明：**
- **红色填充行**：今天总缺料为0（表示该物料已不缺料）
- **红色字体（变化量列）**：变化量与今天总缺料不一致（异常变化）
- **红色字体（昨天总缺料列）**：昨天为0，今日新增的缺料
- **红色字体（供应商在途量列）**：有在途物料
- **物料号单元格背景色**：保留自今日Excel的原始颜色标记

## 5. 数据查询导出

此页面用于查看比对结果数据、搜索特定物料、导出查询结果，以及进行出货匹配与删除操作。

### 5.1 搜索数据

1. 点击侧边栏的 **「数据查询」**
2. 在搜索框中输入物料号进行搜索
   - **单个搜索**：直接输入物料号，如 `ABC123`
   - **多个搜索**：用逗号分隔，如 `ABC123,DEF456,XYZ789`
   - **精确匹配**：输入完整匹配键格式 `物料号|销售订单|销售订单行号|内需单号`
3. 搜索结果实时显示在下方表格中，匹配行以浅蓝色背景高亮

**辅助操作：**
- **「导入搜索条件」**：从Excel文件导入一批物料号作为搜索条件
- **「导出搜索结果」**：将当前搜索结果导出为Excel文件
- **「清空」**：清空搜索框，恢复显示全部数据

### 5.2 出货匹配与删除

用于将已出货的物料从数据库中移除：

1. 点击 **「导入出货Excel」**，选择供应商的送货单Excel
2. 系统自动匹配数据库中的记录，匹配项以 **红色背景** 高亮显示并自动勾选
3. 匹配项自动排列在表格顶部
4. 勾选需要删除的记录（已自动勾选匹配项）
5. 点击 **「删除匹配项」**
6. 在弹出的确认对话框中点击 **「是」** 确认删除

> **注意：** 删除操作不可撤销，请确认后再执行。

### 5.3 导入/导出数据

- **「导入Excel」**：将Excel文件导入到数据库表格中
- **「导出Excel」**：将当前表格中的全部数据导出为Excel文件
- **「清空」**：清空当前表格中的所有数据

### 5.4 勾选操作

- **「全选」**：勾选表格中的所有行
- **「取消全选」**：取消所有行的勾选

## 6. 数据库管理

此页面用于浏览和管理SQLite数据库中存储的历史数据。

### 6.1 查看数据

1. 点击侧边栏的 **「数据库」**
2. 表格自动加载数据库中的一级表格数据
3. 数据按录入时间排序显示

### 6.2 数据库表结构

系统使用SQLite数据库（`TCL表格数据库.db`），包含以下表格：

| 表名 | 说明 |
|------|------|
| 一级表格 | 每次比对的主数据（按物料号+订单号唯一，自动更新） |
| 二级表格 | 关联的明细数据 |
| 出货记录 | 历史出货记录 |
| 表头配置 | 列显示配置 |

### 6.3 分类查询

数据库中的每条记录都根据物料描述自动分类为以下类别：

| 分类 | 匹配关键词 |
|------|-----------|
| 透明商标类 | 透明、商标、白色PET |
| 铝箔类 | 银、铝箔、电化铝箔 |
| 接线类 | 接线 |
| 能源能效类 | 能源、能效 |
| 标贴类 | 型号标贴、机型标贴、纸箱标贴、不可移铜版纸、不可移光粉纸、指示标贴 |
| 说明书类 | 说明书、合格证、保修卡、清单、附页、手册、用户、书写纸、参数页 |
| 特光类 | 特光 |
| 其他 | 未匹配到以上任何关键词的物料 |
| 未分类 | 物料描述为空的记录 |

## 8. 序号导入（批量导入）

此页面支持批量导入多个Excel文件，自动合并数据并添加订单名称标识。

### 8.1 批量导入操作

1. 点击侧边栏的 **「序号导入」**
2. 在"查询并导出数据库信息"区域：
   - 点击 **「查询表格」** 右侧的 **「浏览」** 选择Excel文件
   - 输入物料号列名（默认为"物料号"）
   - 点击 **「查询并导出」** 从数据库中查询匹配数据
   - 或点击 **「导入到主表格」** 将Excel数据直接导入下方表格

3. 在下方的批量导入区域：
   - 点击 **「导入excel」** 按钮
   - 在文件选择对话框中 **多选** 一个或多个Excel文件（按住Ctrl或Shift键多选）
   - 选择导入模式：
     - **追加**：保留现有数据，添加新文件的数据
     - **替换**：清空现有数据，重新导入
   - 系统自动从每个文件名中提取"订单名称"列并添加到数据中

### 8.2 搜索与筛选

在搜索框中输入物料号进行模糊搜索：
- **单个搜索**：输入物料号关键词
- **多个搜索**：用逗号分隔多个关键词，如 `ABC,DEF,XYZ`
- 搜索结果实时过滤显示

**辅助操作：**
- **「导入搜索条件」**：从Excel文件批量导入搜索关键词
- **「导出搜索结果」**：将过滤后的数据导出为Excel
- **「清空」**：清空搜索框

### 8.3 出货匹配

1. 点击 **「导入出货Excel」** 选择送货单文件
2. 系统自动匹配批量导入数据中的物料号
3. 匹配项红色高亮并自动勾选
4. 点击 **「删除匹配项」** 移除已出货记录

### 8.4 勾选与导出

- **「全选」/「取消全选」**：批量操作勾选框
- **「导出Excel」**：将勾选的行或全部数据导出为Excel文件
- **「清空」**：清空批量导入表格中的所有数据

> **提示：** 导入的数据会自动保存到本地缓存（`batch_import_cache.json`），下次启动时自动恢复。

## 9. 分类导出

此页面用于将数据库中的物料按类别自动分文件导出，方便分配给不同负责人处理。

### 9.1 操作步骤

1. 点击侧边栏的 **「分类导出」**
2. 点击 **「输出目录」** 右侧的 **「浏览」** 按钮，选择导出文件的保存位置
3. 点击 **「导出分类表格」** 按钮

系统自动执行：
1. 从数据库读取一级表格中的所有物料
2. 根据物料描述中的关键词自动分类
3. 每个分类生成一个独立的Excel文件

### 9.2 导出结果

导出完成后，弹窗显示已导出的分类文件列表，例如：

```
已导出 8 个分类文件:

透明商标类: D:\输出目录\透明商标类.xlsx
铝箔类: D:\输出目录\铝箔类.xlsx
接线类: D:\输出目录\接线类.xlsx
标贴类: D:\输出目录\标贴类.xlsx
说明书类: D:\输出目录\说明书类.xlsx
其他: D:\输出目录\其他.xlsx
...
```

> **前提条件：** 需要先通过「表格比对」功能将数据导入数据库，否则会提示"数据库中没有数据"。

## 10. 还需交货统计

此页面用于统计各物料还需供应商交货的数量。

### 10.1 准备文件

需要准备两个Excel文件：

| 文件 | 说明 | 必须包含的列 |
|------|------|-------------|
| 供货计划 | 供应商的供货计划表 | `物料号`、`物料描述`、`总缺料`、`供应商在途量`、`已承诺量` |
| 送货单 | 实际送货明细 | `物料编码`、`收货数量` |

### 10.2 操作步骤

1. 点击侧边栏的 **「还需交货」**
2. 点击 **「供货计划」** 右侧的 **「浏览」** 按钮，选择供货计划Excel文件
3. 点击 **「送货单」** 右侧的 **「浏览」** 按钮，选择送货单明细Excel文件
4. 点击 **「计算还需交货」** 按钮

系统自动执行：
1. 读取供货计划和送货单数据
2. 按物料号汇总已送货数量
3. 计算 `还需交货 = 总缺料 - 已送货`
4. 只显示还需交货数量大于0的记录
5. 按还需交货数量从大到小排序

### 10.3 结果表格

表格显示以下列：

| 列名 | 说明 |
|------|------|
| 物料号 | 物料编码 |
| 物料描述 | 物料名称 |
| 总缺料 | 供货计划中的总缺料数量 |
| 已送货 | 已累计送货数量 |
| 还需交货 | 总缺料 - 已送货 |
| 在途 | 供应商在途量 |
| 已承诺 | 供应商已承诺量 |

### 10.4 导出结果

点击 **「导出Excel」** 按钮，将还需交货数据保存为Excel文件。

## 11. 常见问题

### Q1: 比对时提示"请选择昨天和今天的表格文件"

**原因：** 未选择昨天或今天的Excel文件。

**解决：** 确保"昨天表格"和"今天表格"两个输入框中都有有效的文件路径。

### Q2: 比对结果中变化量全部为0

**原因：** 昨天和今天的Excel文件内容完全相同。

**解决：** 确认是否选择了正确的日期文件。如果确实没有变化，这是正常结果。

### Q3: 出货匹配没有找到任何匹配项

**原因：** 出货Excel中的物料号与数据库中的物料号不一致。

**解决：**
- 检查出货Excel是否包含 `物料号` 列（或 `物料编码` 列）
- 确认物料号格式一致（注意空格、大小写）
- 如果需要精确匹配，确保出货Excel中包含 `销售订单`、`销售订单行号`、`内需单号` 列

### Q4: 分类导出提示"数据库中没有数据"

**原因：** 数据库中没有比对记录。

**解决：** 先在「表格比对」页面执行一次比对操作，数据会自动写入数据库。

### Q5: 切换到服务器模式后数据为空

**原因：** 服务器数据库中没有数据，或服务器连接失败。

**解决：**
- 点击 **「测试」** 按钮确认服务器连接正常
- 确认服务器端已有数据（需要有其他客户端先同步过数据）
- 如需将本地数据同步到服务器，先在本地模式下完成比对，再切换到服务器模式

### Q6: 批量导入时部分文件导入失败

**原因：** 文件格式不兼容或文件损坏。

**解决：**
- 确认所有文件都是 `.xlsx` 或 `.xls` 格式
- 确认每个文件的第一行是表头
- 确认文件中包含 `物料号` 列
- 错误的文件会被跳过，其他文件正常导入

### Q7: 还需交货统计提示"计算失败"

**原因：** Excel文件缺少必要的列。

**解决：**
- 供货计划文件必须包含 `物料号` 和 `总缺料` 列
- 送货单文件必须包含 `物料编码` 和 `收货数量` 列
- 注意列名必须完全匹配（区分大小写）

### Q8: 程序启动后界面显示异常

**原因：** 可能是Qt渲染问题。

**解决：**
- 尝试调整窗口大小
- 重新启动程序
- 如果问题持续，检查Python和PyQt5版本是否匹配（推荐Python 3.8 + PyQt5 5.15.9）
